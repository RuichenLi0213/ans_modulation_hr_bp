# Reduced ANS–CVS Model

A minimal, transparent, closed-loop cardiovascular model with autonomic
nervous system (ANS) modulation of **heart rate** and **blood pressure**,
plus a phenomenological **wave-reflection** mechanism that gives the
arterial pressure waveform a realistic secondary peak.

The project is a *reduced conceptual model* distilled from a large
research-grade Fortran cardiovascular simulator (`cvs.f90`). It keeps the
original autonomic regulation formulas but replaces the full 1-D vascular
network with a single artery–vascular-bed–vein loop, so the whole model
fits in one short, readable, dependency-free Fortran file per stage.

> ⚠️ **Scope.** This is a teaching / sensitivity-analysis / concept model.
> It is **not** a clinical tool and must not be used for diagnosis or
> patient-specific prediction. See [Limitations](#limitations).

## What the model does

The flagship file `ans_cvs_integrated.f90` simulates, in one closed loop:

- **ANS-mediated heart-rate modulation** — a baroreflex-style sigmoid
  controller that adjusts HR.
- **ANS-mediated blood-pressure modulation** — a sigmoid controller that
  adjusts systemic vascular resistance.
- **A pulsatile arterial pressure waveform** generated by a periodic
  cardiac inflow driving a Windkessel-type artery.
- **Forward + reflected wave morphology** — a delayed, scaled copy of the
  forward inflow produces a secondary peak / late-systolic shoulder.
- **A resistance disturbance** that sets different initial blood-pressure
  levels.

Two smaller files isolate the building blocks and are useful for teaching
and for testing each mechanism on its own.

## Quick start

### Requirements

- A Fortran 90/95 compiler (`gfortran` recommended).
- Python 3 with `numpy` and `matplotlib` (for plotting only).

Install `gfortran`:

```bash
# macOS (Homebrew)
brew install gcc
# Debian / Ubuntu
sudo apt install gfortran
# Windows: use WSL with the commands above, or install MinGW-w64.
```

### Build and run the integrated model

```bash
gfortran -O2 -Wall ans_cvs_integrated.f90 -o ans_cvs_integrated
./ans_cvs_integrated
python3 plot_ans_cvs.py
```

This writes three `.dat` files and the plotting script renders the HR,
arterial waveform, ANS activities and vascular resistance over time.

### Build and run the component models

```bash
gfortran -O2 -Wall bp_modulation_simplified.f90 -o bp_modulation_simplified
./bp_modulation_simplified
python3 plot_bp_modulation.py

gfortran -O2 -Wall bp_modulation_reflected.f90 -o bp_modulation_reflected
./bp_modulation_reflected            # defaults
./bp_modulation_reflected 0.0 0.25   # k_reflect=0 (no reflection), tau=0.25 s
./bp_modulation_reflected 0.45 0.30  # strong, later reflection
python3 plot_bp_reflected.py
```

`bp_modulation_reflected` accepts two optional command-line arguments:
`k_reflect_base` and `tau_reflect`.

## The closed-loop model

```
heart / inflow source
        |  Q_in (forward + reflected)
        v
   characteristic artery   (compliance C_art)
        |  Q_out = (P_art - P_ven) / R_vb
        v
   characteristic vascular bed   (resistance R_vb, ANS-modulated)
        |
        v
   characteristic vein   (compliance C_ven)
        |  Q_return = (P_ven - P_RA) / R_ven
        v
   reservoir  (P_RA)  --> back to heart
```

Governing equations (explicit Euler, fixed step `dt = 5e-5 s`):

```
Q_out      = (P_art - P_ven) / R_vb
Q_return   = max(0, (P_ven - P_RA) / R_ven)
dP_art/dt  = (Q_in_total - Q_out)    / C_art
dP_ven/dt  = (Q_out      - Q_return) / C_ven
```

**Cardiac inflow.** A half-sine ejection during systole, zero in
diastole, scaled so that one cycle delivers the stroke volume `SV`:

```
Q_forward(t) = Q_peak * sin(pi * tcr / t_systole)   for tcr < t_systole
Q_peak       = SV * pi / (2 * t_systole * (1 + k_reflect))   (mass-preserving)
```

The cardiac phase `tcr` is advanced incrementally (`tcr += dt`, wrapped at
`tduration = 1/HR`) so it stays continuous when HR changes.

**Units:** pressure `mmHg`, time `s`, flow `mL/s`, volume `mL`,
compliance `mL/mmHg`, resistance `mmHg*s/mL`, HR `beats/s`.

## ANS modulation

Both controllers use the same sigmoid-activation + first-order-relaxation
structure inherited from the original `cvs.f90` / `ans_modulation.f90`.
**These formulas are preserved verbatim.**

### Heart rate (`neuro_hr`)

```
ns_hr      = 1 / (1 + (HR / miu_hr) ^  niu_s_hr)      ! SNS activity
np_hr      = 1 / (1 + (HR / miu_hr) ^  niu_p_hr)      ! PSNS activity
EneuHR_raw = AneuHR_hr * ns_hr - BneuHR_hr * np_hr + CneuHR_hr
```

`HR` then relaxes toward the (gain-blended) equilibrium by a 4th-order
Runge–Kutta step with time constant `TneuHR_hr`.

### Blood pressure (`neuro_bp`)

```
P_afferent : low-pass-filtered P_art (MAP-like afferent signal)
ns_p     = 1 / (1 + (P_afferent / miu_p) ^  niu_s_p)
np_p     = 1 / (1 + (P_afferent / miu_p) ^  niu_p_p)
R_eq_raw = R0_base + AneuR * (ns_p - 0.5) - BneuR * (np_p - 0.5)
```

`R_vb` then relaxes toward the (gain-blended) equilibrium by first-order
Euler with time constant `TneuR`.

> The resistance equilibrium uses a **deviation form** so that at neutral
> ANS (`ns_p = np_p = 0.5`) we get `R_eq = R0_base` exactly — no baseline
> drift. By default `BneuR = 0`: direct parasympathetic control of
> systemic resistance is minimal, so PSNS influences BP mainly *indirectly*
> through HR.

## Wave reflection

Real arterial waveforms show a secondary peak / shoulder after the primary
systolic peak, produced largely by **peripheral wave reflection**. A
two-element Windkessel cannot reproduce this (it is a first-order low-pass
system with a single-peak input).

This model adds the feature phenomenologically with a **delayed reflected
inflow**:

```
Q_reflected(t) = k_reflect * Q_forward(t - tau_reflect)
Q_in_total(t)  = Q_forward(t) + Q_reflected(t)
```

A small circular buffer stores past `Q_forward` values. Properties:

- `k_reflect = 0` -> reduces exactly to the single-peak model.
- Larger `k_reflect` -> more prominent secondary peak.
- Larger `tau_reflect` -> secondary peak appears later in the cycle.
- **Mass preservation** (`mass_preserve = .true.`, default): `Q_peak` is
  rescaled by `1/(1+k_reflect)` so the cycle-integrated inflow stays equal
  to `SV`. This keeps MAP comparable across `k_reflect` values; only the
  *waveform shape* changes, not the mean pressure.
- Optional `couple_kreflect_R = .true.` makes reflection strength scale
  with vascular tone: `k_reflect_eff = k_reflect * R_vb / R0_base`.

This is **not** a wave-propagation solver — it cannot represent multiple
reflection sites, spatial gradients, or the dicrotic notch.

## Disturbance module

`disturbance()` sets different initial blood-pressure levels by acting
**only on the vascular-bed resistance**. During the window
`n_dist_onset <= nstep <= n_dist_end` it forces:

```
R_vb = R_dist_factor * R0_base
```

It does **not** modify HR, stroke volume, compliance, venous pressure, or
the ANS targets — those stay fixed in `parameterset()`. Outside the window
the resistance is governed by the warm-up initial value (before ANS onset)
or by `neuro_bp` (after onset).

| `R_dist_factor` | Effect |
|---|---|
| `1.0` | disturbance disabled |
| `1.5` (default) | moderate hypertensive perturbation |
| `2.0` | matches the original `cvs.f90` setting (`SVB_R = 2*R0`) |

## Smooth ANS onset (BP-spike fix)

Earlier versions produced a non-physiological BP spike at the instant ANS
modulation switched on. Two discontinuities caused it, both now fixed:

1. **Cardiac-phase jump.** The phase was rebuilt from absolute time
   (`tcr = time - tduration*int(time/tduration)`), which jumps whenever HR
   (hence `tduration`) changes, scrambling the ejection timing and
   injecting a spurious inflow pulse. **Fix:** advance the phase
   incrementally and wrap against the current cycle length.

2. **Hard controller switch.** The sigmoid activities flipped from a fixed
   `0.5` to their live values at onset, stepping the equilibrium targets.
   **Fix:** a raised-cosine gain ramp,

   ```
   ans_gain = 0.5 * (1 - cos(pi * min(1, (t - t_onset) / T_ramp)))
   ```

   applied **only** to the deviation terms:

   ```
   EneuHR_hr = CneuHR_hr + ans_gain * (EneuHR_raw - CneuHR_hr)
   R_eq      = R0_base   + ans_gain * (R_eq_raw   - R0_base)
   ```

   The raw `neuro_hr` / `neuro_bp` formulas are untouched; the ramp only
   controls how quickly their effect is phased in (over `T_ramp = 4 s` by
   default). At onset `ans_gain = 0`, so the targets equal their baselines
   and there is no jump.

Use `plot_ans_cvs_compare.py` to reproduce the before/after figures.

## Output files

All files are plain text, written to the working directory, with a
`#`-prefixed header line. Per-step files are sampled every `nprint` steps.

### `ans_cvs_integrated.f90`

**`ANS_CVS_waveform.dat`**

| Col | Name | Unit | Meaning |
|---|---|---|---|
| 1 | `time` | s | simulation time |
| 2 | `HR` | beats/s | current heart rate |
| 3 | `P_art` | mmHg | arterial pressure |
| 4 | `P_ven` | mmHg | venous pressure |
| 5 | `Q_forward` | mL/s | forward cardiac inflow |
| 6 | `Q_reflected` | mL/s | delayed reflected inflow |
| 7 | `Q_in_total` | mL/s | `Q_forward + Q_reflected` |
| 8 | `Q_out` | mL/s | artery -> vein flow |
| 9 | `Q_return` | mL/s | venous return |
| 10 | `R_vb` | mmHg*s/mL | vascular-bed resistance |

**`ANS_activity.dat`**

| Col | Name | Unit | Meaning |
|---|---|---|---|
| 1 | `time` | s | simulation time |
| 2 | `HR_afferent` | beats/s | HR signal seen by `neuro_hr` |
| 3 | `BP_afferent` | mmHg | low-pass-filtered `P_art` seen by `neuro_bp` |
| 4 | `ns_hr` | — | SNS activity (HR) |
| 5 | `np_hr` | — | PSNS activity (HR) |
| 6 | `ns_bp` | — | SNS activity (BP) |
| 7 | `np_bp` | — | PSNS activity (BP) |
| 8 | `HR_eq` | beats/s | equilibrium HR (after gain blend) |
| 9 | `R_eq` | mmHg*s/mL | equilibrium resistance (after gain blend) |
| 10 | `HR` | beats/s | current HR (repeated for convenience) |
| 11 | `R_vb` | mmHg*s/mL | current resistance |
| 12 | `ans_gain` | — | ANS onset ramp (0 -> 1) |

**`ANS_CVS_summary.dat`** — one line per completed cardiac cycle.

| Col | Name | Unit | Meaning |
|---|---|---|---|
| 1 | `cycle` | — | cycle index |
| 2 | `time` | s | end-of-cycle time |
| 3 | `HR` | beats/s | heart rate this cycle |
| 4 | `SBP` | mmHg | systolic (max `P_art`) |
| 5 | `DBP` | mmHg | diastolic (min `P_art`) |
| 6 | `MAP` | mmHg | mean `P_art` |
| 7 | `pulse_pressure` | mmHg | `SBP - DBP` |
| 8 | `R_vb` | mmHg*s/mL | resistance at cycle boundary |

### Component models

`bp_modulation_simplified.f90` and `bp_modulation_reflected.f90` write
`BP_waveform.dat`, `Neuro_BP.dat`, and `BP_summary.dat`. The reflected
version's `BP_waveform.dat` additionally splits inflow into `Q_forward`
and `Q_reflected`. See the header line of each file for the exact column
order.

## Key parameters

All defaults live in `subroutine parameterset()`; ANS gains, setpoints and
sigmoid slopes live in `neuro_hr()` / `neuro_bp()`.

| Parameter | Default | Unit | Meaning |
|---|---|---|---|
| `dt` | 5e-5 | s | time step |
| `nlast` | 1 800 000 | steps | total length (~90 s) |
| `nprint` | 100 | steps | output interval |
| `n_onset` | 400 000 | step | ANS engages (~20 s) |
| `n_dist_onset` | 100 000 | step | disturbance start (~5 s) |
| `n_dist_end` | 300 000 | step | disturbance end (~15 s) |
| `T_ramp` | 4.0 | s | ANS onset ramp duration |

| Parameter | Default | Unit | Meaning |
|---|---|---|---|

| `SV` | 70.0 | mL | stroke volume (fixed) |
| `t_systole` | 0.30 | s | systolic ejection duration |
| `C_art` | 1.5 | mL/mmHg | arterial compliance |
| `C_ven` | 100.0 | mL/mmHg | venous compliance |
| `R0_base` | 1.0 | mmHg*s/mL | baseline vascular-bed resistance |
| `R_ven` | 0.04 | mmHg*s/mL | venous-return resistance |
| `P_RA` | 2.0 | mmHg | reservoir pressure |

| Parameter | Default | Unit | Meaning |
|---|---|---|---|

## Customising the model

1. Open the `.f90` file in a text editor.
2. Edit values in `parameterset()` (and ANS gains in `neuro_hr` /
   `neuro_bp` if needed).
3. Recompile and rerun.

Common experiments:

- **Turn reflection off:** `k_reflect_base = 0.0d0` -> single-peak waveform.
- **Stronger / later secondary peak:** raise `k_reflect_base` toward 0.5;
  raise `tau_reflect` toward 0.30.
- **Different initial BP:** change `R_dist_factor` (1.0 disables it).
- **Faster / slower baroreflex:** lower / raise `TneuR`, `TneuHR_hr`.
- **Smoother or sharper ANS engagement:** raise / lower `T_ramp`.
- **Stiffer artery (aging-like):** lower `C_art` *and* raise
  `k_reflect_base` together.

## Interpreting the results

A default integrated run proceeds as:

1. **0–5 s — warm-up.** HR fixed at 100 bpm, `R_vb = 1.0`; the Windkessel
   settles to ~100/79/93 mmHg (SBP/DBP/MAP).
2. **5–15 s — disturbance.** `R_vb` forced to 1.5; MAP rises (~170 mmHg).
3. **15–20 s — disturbance off, ANS still off.** `R_vb` stays at 1.5.
4. **20 s — ANS engages (ramped over 4 s).** HR (> target) is driven down;
   `R_vb` (and BP, > setpoint) is driven down. No onset spike.
5. **20–40 s — recovery.** HR settles ~76 bpm; `R_vb` relaxes back.
6. **> 40 s — steady state.** HR ~76 bpm, MAP ~95 mmHg (= setpoint),
   `R_vb` ~1.0. Each beat still shows the primary + secondary peak.

Because the controller is proportional, MAP converges to the setpoint only
when the disturbance has cleared; a sustained disturbance would be
attenuated but not fully eliminated.

## Simplifications vs. the original cvs.f90

Removed or replaced:

- Full 1-D vascular tree, multiple vessels, multiple vascular beds.
- 0-D four-chamber heart, elastance functions, cardiac–1-D characteristic
  coupling (Newton–Raphson).
- Respiratory module and intrathoracic-pressure terms.
- Body-weight scaling laws.
- Anchored exponential-recovery form of the resistance update -> replaced
  by a continuous first-order ODE.
- Constant-offset resistance equilibrium -> replaced by the deviation form.

The autonomic regulation **formulas** (sigmoid activations, equilibrium
expressions, RK4 HR update) are preserved; only the variable interfaces
and the integration of the recovery dynamics were adapted.

## Limitations

- The reflected wave is a phenomenological approximation (single delay
  buffer); **no** real wave propagation, multiple reflection sites, or
  dicrotic notch.
- No spatial information (no pulse-wave velocity, no geometry).
- No pulmonary circulation; no respiratory modulation.
- Cardiac inflow is prescribed (no Frank–Starling / preload coupling); SV
  is fixed.
- ANS modulation is phenomenological, not a full neurophysiological model.
- Parameter values are for conceptual demonstration and sensitivity
  analysis, not subject-specific calibration.
- With the default single-bed disturbance, MAP transients are larger than
  the multi-bed original would give; reduce `R_dist_factor` for milder
  perturbations.
- **Not for clinical use.**
